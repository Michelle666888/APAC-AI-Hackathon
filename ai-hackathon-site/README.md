# AI Genesis landing page

Open `index.html` in a browser to preview the page locally.

## Editing the page

Use the **Edit page** control in the lower-right corner to edit visible text directly.

- **Save draft** keeps changes in browser storage on the current device.
- **Export HTML** creates a new HTML file with the edited copy embedded in it. Keep the exported file beside `styles.css`, `script.js`, and the `assets` folder so the complete design and interactions remain available.
- **Reset** clears the locally saved draft and restores the source copy.

Keyboard shortcuts: `Ctrl/Cmd + S` saves the draft and `Esc` exits edit mode.
